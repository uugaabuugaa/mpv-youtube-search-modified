# mpv-youtube-search-modified

Edited from [Luendor's mpv-youtube-search script (extended version)](https://github.com/Lunedor/mpv-youtube-search ).

Probably not a good idea to use it since it's meant for personal use and i edited it using Claude. Although I don't know what mistakes are in it everything kind of just works. Feel free to take a look and use/edit/fix if there's any mistakes here.

### Extra stuff:
- uosc integration for search input field and feed options listing (home/recommendation,subscription etc.)
- added extra feed options for related video based on "all" and "related" chips in youtube
- make search input stay available in next search field popup for same mpv instance
- keep cache from search, home, related fetches for a duration of choice (independent of mpv instance, can be refetched at will)
- made it purple cause it's cuter
- better arrow navigation (n/p still works but arrow keys can navigate pages and within rows too)
- better thumbnail view
- fix screen flicker
